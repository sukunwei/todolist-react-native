一、一句話說明

本 App 不收集、不上傳、不共享、不分析任何使用者資料。

你寫下的每一條待辦事項，只存在於你自己的手機裡，從未離開過你的裝置。

二、我們收集哪些資訊

我們不收集任何資訊，包括但不限於：

  • 姓名、郵箱、電話號碼等身分資訊
  • 裝置標識符（IDFA、IDFV、裝置序列號等）
  • 位置資訊
  • 使用資料、崩潰日誌、性能分析資料
  • 廣告標識符

本 App 沒有帳號體系，沒有登錄，沒有註冊，也沒有埋點與統計 SDK。

三、App 在你的裝置上儲存什麼

為了讓 App 能正常工作，App 會在裝置本機的應用沙盒內保存以下內容：

內容 儲存位置 用途
待辦事項（標題、備註、優先級、完成狀態、創建時間） 裝置本機沙盒 展示你的清單
介面臨時狀態（當前選中的篩選條件） 記憶體 關閉 App 後即失效，不落盤

這些資料：

  • 只保存在本機，不會上傳到任何伺服器；
  • 不經我們之手——我們沒有、也無法讀取這些資料；
  • 不會用於任何目的，包括廣告、使用者輪廓分析與資料分析。

由於資料僅存在於本機，卸載 App 即徹底刪除全部內容，且無法恢復。如果你希望提前清除，可以在 App 內使用「清除已完成」，或直接刪除 App。

四、我們不請求任何系統權限

本 App 不申請任何系統權限，包括但不限於：

  • 通知 / 推送
  • 相機、相冊、麥克風
  • 位置、通訊錄、日曆
  • 追蹤權限（App Tracking Transparency）

因此本 App 不會在 iOS 設定中留下任何權限記錄。

五、第三方元件

本 App 主要包含以下開源軟體元件，它們以靜態連結方式編譯進 App，均不包含追蹤、廣告或資料分析功能：

元件 用途 連線行為
React Native 跨平臺 UI 框架 無
React Navigation 頁面導航 無
Zustand 狀態管理 無
AsyncStorage 本機鍵值儲存 無
react-native-haptic-feedback 觸感回饋 無
Hermes JavaScript 引擎 無

App 在運行期間不會發起任何網路請求。

六、面向兒童

本 App 不收集任何資料，因此不涉及也不會收集兒童的個人資訊。我們不面向 13 歲以下兒童提供服務，監護人無需就資料收集向我們提出特別請求。

七、你的權利

由於我們不持有任何使用者資料，你對本 App 資料的全部控制權就是裝置本身：

  • 查看、修改、刪除 —— 在 App 內直接操作；
  • 全部清除 —— 刪除 App 即可，我們這邊沒有任何副本需要處理；
  • 資料可攜帶 —— 你的資料始終以可讀的形式存在你的裝置上。

因為我們不收集資料，不存在查閱、更正、導出或刪除個人資訊的請求流程——這類請求在我們的系統中沒有對應記錄。

八、本政策的變更

若本政策發生實質性變更（例如 App 新增了連線功能），我們會：

  1. 更新本頁頂部的「生效日期」；
  2. 在 App Store 的版本更新說明中說明變更內容。
